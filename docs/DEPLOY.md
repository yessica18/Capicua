# Publicar CAPICÚA en GitHub Pages (gratis)
1. Crea un repo público en github.com llamado `capicua-ultima-version` (GitHub no admite tildes en nombres de repo).
2. Sube TODO el contenido de esta carpeta a la raíz del repo (index.html debe quedar en la raíz).
3. Settings → Pages → Branch: main / root → Save.
4. Tu dirección gratis: https://TU-USUARIO.github.io/capicua-ultima-version/
5. Reemplaza TU-USUARIO en index.html. Para un dominio propio gratis tipo .is-a.dev o eu.org, agrega un archivo CNAME.
6. Abre capicua-final.js y completa PAY_CONFIG (titular y cuentas). Para cobrar de verdad conecta Wompi (Colombia) y Stripe/PayPal con un backend (backendUrl).
